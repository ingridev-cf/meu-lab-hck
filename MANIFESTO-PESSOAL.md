# Meu Manifesto Pessoal

## Por que eu estou aqui?
Eu não estou aqui para decorar comando. Quero entender como as coisas funcionam por dentro e usar isso para construir e proteger, nunca para invadir o que não é meu.

## O que eu prometo a mim mesmo?
1. Só ataco o que é meu ou o que eu tenho autorização para atacar.
2. Documento cada laboratório como se fosse prestar contas.
3. Entendo o "porquê" antes de copiar o "como".
